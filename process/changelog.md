## Change 1
What changed: Combined the four separate Calibration tests into one system using cursor speed as the single shared input.
Why: The brief required one dominant gesture instead of four separate, disconnected demos.

## Change 2
What changed: Redesigned the page with a dark navy theme, card-style panels, and a framed canvas instead of plain stacked text.
Why: The original layout looked like a bunch of unstyled text with no visual hierarchy.

## Change 3
What changed: Replaced the growing/fracturing sigil with a new drawing system — slow cursor movement draws soft curves and circular nodes, fast movement shatters the drawing into sharp geometric shards.
Why: Wanted the system to feel more like a living artwork rather than a single reactive shape.

## v2 Change 1
What changed: Removed the geometric shatter/shard behavior entirely.
Why: It was the noisiest, least controlled part of v1 — no limit on how much could accumulate.

## v2 Change 2
What changed: Tightened the remaining curve rule into a single clean threshold, with fast movement now causing the existing drawing to dissolve quickly instead of adding new shapes.
Why: This turns the system into one legible state shift (building vs. dissolving) instead of two competing effects.
